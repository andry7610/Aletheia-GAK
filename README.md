# ⚖️ Aletheia-GAK

[![CI](https://github.com/andry7610/Aletheia-GAK/actions/workflows/python-package.yml/badge.svg)](https://github.com/andry7610/Aletheia-GAK/actions/workflows/python-package.yml)
![tests](https://img.shields.io/badge/tests-113_passed-brightgreen)

**Нейросимволический движок-верификатор для физических гипотез, генерируемых ИИ.**

Генеративные нейросети (LLM) блестяще пишут код, но часто галлюцинируют в размерностях, забывают коэффициенты (1/2, 2*pi) или путают константы (например, постоянную Планка `h` и приведённую `hbar`).
**Aletheia-GAK** — это строгое «инженерное сито» между нейросетью и вашим солвером. Он проверяет уравнения на физическую состоятельность **до** того, как они попадут в расчёт.

## ✨ Что внутри (Стек технологий)

- **Левое полушарие (Символьная логика):** безопасный AST-парсер + `Pint` для проверки размерностей и `SymPy` для алгебраической сверки с каноническими законами.
- **Гиппокамп (Память):** `SQLite`-база физических величин и эталонных законов с каскадной сверкой тождества целых уравнений. Загружена константами CODATA-2022 (со значениями и тождественной самопроверкой) и 20 каноническими законами — от второго закона Ньютона до полного квадрата уравнений Максвелла с током смещения.
- **Слой Фактов:** `facts.py` — свойства материалов с паспортом происхождения (эксперимент / DFT / Calphad), условиями измерения и трёхступенчатым вердиктом PASS / WARN / FAIL: «закон проверяется SymPy, факт — границей доверия». Мост к оркестратору: evaluate_material_hypothesis даёт LLM единый словарь вердикта от законов и фактов.
- **Слой вывода:** `derivation.py` — каскад, выводящий следствия из посаженных законов: уравнение непрерывности заряда ВЫВОДИТСЯ из полного Ампера и Гаусса, а не хранится наизусть.
- **Мост к LLM:** `llm_bridge.py` реализует цикл самоисправления: `LLM выдала ошибку -> Верификатор поймал -> Отправил фидбек -> LLM исправилась`.
- **MCP-Сервер:** `mcp_server.py` — универсальная «розетка» для Claude Desktop, Cursor и Windsurf.
- **Web UI:** `streamlit_app.py` — визуальный плейграунд для проверки формул в браузере.

## 🚀 Быстрый старт

1. **Установите зависимости:**
```bash
pip install sympy pint pytest streamlit openai mcp
```

2. **Наполните базу знаний (создаст aletheia_memory.db):**
```bash
python seed_db.py
```

3. **Прогоните тесты (113/113 зелёных):**
```bash
python -m pytest -v
```

4. **Запустите цикл самокоррекции (демо в консоли):**
```bash
python llm_bridge.py
```

5. **Откройте веб-интерфейс:**
```bash
streamlit run streamlit_app.py
```

## 🧩 Пример работы

Представьте, что LLM сгенерировала уравнение энергии фотона `E = hbar * f` — размерности сходятся, но физика неверна: потерян множитель `2*pi`.

```python
from orchestrator import AletheiaOrchestrator

brain = AletheiaOrchestrator()
# ... загрузка базовых знаний (h, hbar, f, E) и законов ...

# 1. Ловим галлюцинацию
res_fail = brain.evaluate_hypothesis("E = hbar * f", law_name="photon_energy")
print(res_fail["status"])            # FAIL
print(res_fail["feedback_for_llm"])  # "Размерности верные, но физика не сходится... Проверьте константы (h vs hbar)."

# 2. LLM исправляется (или мы сами исправляем)
res_pass = brain.evaluate_hypothesis("E = h * f", law_name="photon_energy")
print(res_pass["status"])            # PASS
print(res_pass["message"])           # "OK: размерности и алгебра сходятся с законом 'photon_energy'."
```

Сверка с каноном работает каскадом из трёх уровней: прямое тождество уравнений -> пропорциональность с точностью до константы -> эквивалентность множеств решений. Поэтому перевёрнутые, но физически верные формы (например, `m = E/c**2` против канона `E = m*c**2`) корректно проходят проверку. В v1.1 каскад научился и первому канону с нулевой правой частью: уравнению непрерывности `div_J + drho_dt = 0`. В v1.3 каскад научился не только сверять законы с каноном, но и ВЫВОДИТЬ законы из законов: непрерывность заряда следует из полного Ампера и Гаусса через слой тождеств.

## 📂 Структура проекта

```
Aletheia-GAK/
├── verifier.py          # Проверка размерностей (AST + Pint)
├── vector_ops.py        # Векторная алгебра: grad/div/rot, ранги и типы
├── identities.py        # Тождества векторного анализа: div(rot A)=0, rot(grad phi)=0
├── derivation.py        # Слой вывода: непрерывность заряда выводится из полного Ампера и Гаусса
├── facts.py             # Слой Фактов: свойства материалов с паспортом происхождения
├── maxwell_seed.py      # Каноны уравнений Максвелла (v1.3: полный Ампер с током смещения)
├── graph_db.py          # База знаний (SQLite + SymPy, каскадная сверка)
├── seed_db.py           # Наполнение базы: CODATA-2022, операторы, законы
├── orchestrator.py      # Мозг, объединяющий проверки
├── llm_bridge.py        # Мост к API нейросетей (DeepSeek, GigaChat)
├── mcp_server.py        # MCP-сервер для интеграции с IDE
├── streamlit_app.py     # Веб-интерфейс
└── test/                # 113/113 зелёных тестов (pytest)
```

## 🗺 Roadmap

- **✅ v1.0** — Ядро + LLM-мост + MCP-сервер + Web UI.
- **✅ v1.1** — Уравнение непрерывности: первый канон с нулевой правой частью. 31 зелёный тест.
- **✅ v1.2** — Уравнения Максвелла: векторная алгебра, `grad`/`div`/`rot`/`ddt`, слой тождеств (`div(rot A)=0`, `rot(grad phi)=0`), канон Максвелла в Гиппокампе. 77 зелёных тестов.
- **✅ v1.3** — Полный закон Ампера—Максвелла (ток смещения). Непрерывность заряда теперь не хранится в каноне, а ВЫВОДИТСЯ из него каскадом. 95 зелёных тестов.
- **✅ v1.4** — Слой Фактов с паспортом происхождения: `exp_type` (measured / lower_bound / unknown), трёхступенчатый вердикт PASS/WARN/FAIL с процентом превышения и честным запасом. Первая партия: HfCN (4273 K нижняя граница / 4400 K DFT), W, SiC, подвижности ионов для Bio-COMSOL. 105 зелёных тестов.
- **🛠 v2.0** — Интеграция с Bio-COMSOL и GAK-WaveCAD (автопроверка уравнений в реальных солверах).
